# Analyzing Employee Satisfaction and Department Ratings Using Simple Linear Regression

A data science project exploring the quantitative relationship between employee satisfaction metrics and department performance ratings using Simple Linear Regression modeling techniques.

## 📌 Project Overview
Understanding what drives department ratings and employee satisfaction is crucial for organizational health, talent retention, and productivity. This project utilizes Simple Linear Regression to analyze how employee satisfaction scores correlate with department ratings, providing actionable statistical insights for human resources and leadership teams.

## 🛠️ Methodology & Evaluation
1. **Data Preprocessing & EDA:** Cleaned workforce survey data, inspected distributions, and visualized linear relationships between satisfaction scores and department ratings.
2. **Model Fitting:** Fitted an Ordinary Least Squares (OLS) Simple Linear Regression model to estimate the linear relationship between employee satisfaction and department performance.
3. **Statistical Evaluation:** Assessed model fit, significance, and assumptions using:
   * **Coefficient of Determination (R²):** Measures the proportion of variance in department ratings explained by employee satisfaction.
   * **p-values:** Evaluates the statistical significance of the regression slope and intercept.
   * **Residual Diagnostics:** Checks linearity, homoscedasticity, and normality of errors.
